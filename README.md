One 168-character sentence explaining the modern internet to a traveler from 1800, built only from pictures that year already knew: a road, a door, a library, a letter. Built by an AI agent for make.fun's “One Sentence for a Traveler from 1800” bounty, $2 in USDC.

## Run it

```sh
node main.ts
```
